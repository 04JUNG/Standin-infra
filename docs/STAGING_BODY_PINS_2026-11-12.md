# 스테이징 모델 자산 고정

2026-11-12 확인 시 실행 중인 스테이징은 최신 anatomy 자산을 사용하지만,
저장된 인프라 설정은 `shape-20261017-m072-f034`를 가리켰다.
이 변경은 현재 실행 중인 자산과 같은 경로·SHA-256을 소스 설정에도 저장한다.
새 조형을 만들거나 동일 파일을 새 버전이라고 재업로드하지 않는다.

| 역할 | 고정 자산 | SHA-256 앞 12자리 |
| --- | --- | --- |
| Converter | `anatomy-presets-20261111-v1` | `f590cdb9f4ed` |
| BFF·분석 worker | `anatomy-presets-20261111-v1` | `0897cb6c18fd` |
| 추론 | 현재 실행 중인 `staging-9-20261012-v1` 유지 | `9acb2ee7ec24` |

기본 모델은 남성 `male-base-v0-8-0`, 여성 `female-base-v0-4-0`이다.
BFF의 기본 내보내기 모델도 남성 base로 유지한다. 남성 8.3등신은 별도 프리셋이다.
추론용 카탈로그와 표시·내보내기 모델 카탈로그는 용도가 다르므로 역할별로 고정한다.

기존 단일 manifest 형식은 운영 등에서 그대로 사용할 수 있다. 새 `manifests`
설정은 역할별 경로·해시만 덮어쓴다. BFF의 추가 프리셋 하위 경로는
`presets-<12자리 hex>` 형식만 허용하고 해당 디렉터리만 S3 읽기를 허용한다.
각 파일의 크기·SHA-256 검증 및 필수 카탈로그 검사는 유지한다.
Converter 전체 묶음은 585,343,701바이트이므로 Python 설치기의 묶음 상한은
실행 중인 설정과 같은 768MiB로 맞추며 파일 하나의 상한 300MiB는 유지한다.

확인한 원본 FBX 해시:

- 남성 base: `705035f1bd247b3bf63a6d293065a5a39390b2d228df559474f9dc6682bf8c43`
- 여성 base: `ffd7b57d6ebba06299be252976b511afe5684a237e6f7d440bb90b2ba20f0c33`

`5999fe397`은 손가락 포즈 전달·재질 처리 코드 버전이며 새 조형 자산 버전은 아니다.
모델 pin을 바꿔야 그 코드가 적용되는 구조가 아니다.

검증은 S3 manifest 원문 해시, ECS 실행 설정, 카탈로그 응답, 설치기 회귀 검사와
CDK 역할별 pin·기본 모델·IAM 경로 검사로 한다. 운영 설정 파일은 수정하지 않는다.
현재 실행 중인 pin과 동일하므로 이 변경만을 위해 서비스를 재시작하지 않는다.
전체 CDK 스택 재배포는 별도로 다른 설정 차이를 검토한 뒤 진행한다.
